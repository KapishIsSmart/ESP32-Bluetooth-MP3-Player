# ESP32-Bluetooth-MP3-Player
ESP32 Bluetooth programs as an MP3 player
change the name to the default name of the bluetooth device
This has 3 programs
one where there r 2 pots(potentiometers), a joystick, an oled screen of 0.96inch (SSD1306) and spi micro sd card reader
second one only has an oled screen of 0.96inch (SSD1306) and spi micro sd card reader and will check capacitance as input
third one is a speech file where it speaks
